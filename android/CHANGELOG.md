# 更新记录

## V1.6.5（2026-08-13）

### 修复

- 修复 Android 节点列表缺少国家/地区显示和国家关键词无法搜索的问题。
- 修复订阅刷新后收藏、延迟、启用状态或当前节点身份丢失的问题。
- 修复 Flutter 进程重建后无法恢复已运行 VPN 状态的问题。
- 修复 Native Core 启动失败时前台通知和 Service 可能残留的问题。
- 修复 `/traffic` 断线后不再重连，以及部分 VLESS 节点右侧实时图表长期为零的问题。
- 修复 Mixed 7890、Clash API 9090 被占用时连接直接失败的问题。

### 改进

- R9 运行参数统一为 TUN 接管、关闭 IPv6、关闭 strict-route 的已验证组合。
- 国家识别同时参考节点名、服务器地址和标签。
- 动态端口会回写设置，确保配置、状态、Clash API 与界面使用实际值。
- Android 关闭系统备份；Native 生命周期状态增加启动时间。

### 版本

- Flutter 应用：`1.6.5+165`
- HongdaCore / sing-box 基线：`1.13.18`
