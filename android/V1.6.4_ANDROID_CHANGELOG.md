# V1.6.4 Android UI Edition

- 新增 Android Flutter 入口，Windows 版继续保留原入口与 Service 逻辑。
- 首页按参考图重做为鸿达星轨智连移动仪表盘。
- 新增 Android 节点、订阅、工具、设置四个页面和 5 项底部导航。
- 首页接入节点延迟、下载/上传速率、连接流量、实时曲线、快速设置与订阅更新。
- Android 存储改用应用私有 data 目录。
- 新增原生 MethodChannel 与 `VpnService` 壳层，避免 Android 误调用 `HongdaService.exe`。
- Android 核心状态明确区分：未集成 `libbox.aar` 时不再报 Windows Service 异常，也不会伪造连接成功。
- Android Gradle/Kotlin 项目骨架、Manifest、图标和构建说明已补齐。
