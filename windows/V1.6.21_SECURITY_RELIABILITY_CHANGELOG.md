# V1.6.21 安全、可靠性与规则性能更新

版本链：鸿达星轨智连 `1.6.21+181` → HongdaService `1.5.8` → HongdaCore `1.10.8`。

## 已完成

- 运行中 TUN 路由每 30 秒巡检，连续两次异常才告警，每五分钟补充 HTTPS 联网检查。
- 客户端日志按 10MB 轮转，保留三份历史文件。
- 连接结束、失败或异常退出后删除运行期配置及原子写入副本。
- Clash API 仅允许回环地址监听。
- HTTPS 订阅禁止降级到 HTTP；不安全 HTTP 必须显式授权。
- IP 规则集改为双栈前缀树匹配。
- 删除尚未由 HongdaCore 实现的 `cache_file` 配置声明。

## 本版本未包含

- 节点、订阅和设置的 DPAPI 静态加密。
- DNS TTL 缓存持久化。
- URLTest 健康阈值、滞回与自动备用节点切换。

这些项目需要独立的数据迁移和真实节点验收，计划在后续版本实施，不能仅增加配置项
或功能声明后标记为完成。

## 验证范围

- Flutter 格式化、静态分析和 Windows 回归测试。
- HongdaCore 普通/`with_gvisor` 测试、`go vet` 与 Windows amd64 构建。
- HongdaService 版本、功能集、内嵌 Core 哈希及 Windows Flutter Release 打包检查。
- 为避免与当前 Karing TUN 冲突，本次不自动启动 HongdaTun；实机联网验收由用户稍后执行。
