# V1.6.2 Responsive Dashboard / Window Fix

- Dashboard no longer switches into a tall stacked layout when the window gets smaller.
- The complete desktop dashboard now scales down proportionally as one canvas (`FittedBox + BoxFit.scaleDown`).
- Removed the dashboard-level vertical `SingleChildScrollView`; normal windowed and maximized desktop use should not require a dashboard scrollbar.
- Reduced card density: connection hero, metric cards, node rows, traffic graph, quick actions and bottom cards are more compact.
- Dashboard shows 5 node rows on the overview page; the full node page still contains all nodes.
- Dashboard top margin was reduced to reclaim usable vertical space.
- Startup window remains a normal resizable window (not maximized), centered at about 86% of the current Windows work area.
- Removed the previous 1640x980 startup cap that made the window look too small on high-resolution/high-DPI displays.
