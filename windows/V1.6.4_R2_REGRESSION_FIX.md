# V1.6.4 R2 Regression Fix

This revision fixes two regressions introduced by the V1.6.4 responsive / region-display changes.

## Fixed

- Dashboard and node-management rows could fail to render for manually-added VLESS nodes whose remark/address did not match a known country keyword. The flag fallback no longer uses an unsafe astral Unicode regex range; it now detects regional-indicator code points safely and falls back to `未知地区` without ever breaking row rendering.
- The left navigation no longer starts collapsed on common normal-window widths. The collapse breakpoint is restored from 1240 logical pixels to 1100 logical pixels. Compact spacing remains active independently so normal window mode still fits without requiring maximization.

## Preserved

- Connected-state manual VLESS node hot-switch with API verification and controlled reload fallback.
- TUN/DNS 172.19.x routing correction.
- Country/region column and responsive layouts.
- The dashboard realtime-traffic data logic remains unchanged, per user request.
