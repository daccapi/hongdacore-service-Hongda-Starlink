# V1.5 收尾变更

## Service 启动链

- 使用用户 Windows + Go 1.26.1 原生编译的自包含 `HongdaService.exe`。
- Service 大小 57,693,184 bytes（约 55.02 MB）。
- SHA256 `948bc39d6d1cc339d2cf7bbade37d5f74a4d2b281183b696ccde8d1d83468c3c`。
- 内嵌 official sing-box 1.13.18 Windows amd64 与 libcronet.dll。
- Flutter 启动前强制执行 Service 大小、`version`、`features` 校验。
- 启动阶段细分为 Service / 权限 / 端口 / 配置 / Doctor / Core / Clash API / IPC / 系统代理。
- 任何阶段失败均进入结构化失败弹窗，可重试或直接查看日志。
- HONGDA_READY 后仍必须等待 Clash API `/version` 成功，再执行 IPC ping/status，避免“进程存在但核心不可用”被误判为连接成功。

## UI / 响应式

- 左侧改为浅色一体式侧栏，不再使用浮动深色/卡片式导航。
- 去掉主导航里多余的“服务状态”，保留内部功能页。
- 主内容上方增加参考图类似的留白，保留无标题栏设计与右上角悬浮窗口按钮。
- 首页连接中显示动画阶段进度、百分比、Service/配置/Core/API/IPC 检查点。
- 启动失败弹窗使用淡入 + 缩放动画，并显示阶段和错误详情。
- 节点页工具栏重新做窄窗口响应式布局。
- 节点表在窄窗口自动切换为紧凑卡片行，避免列宽挤爆。
- 节点测速、延迟变化、开关状态使用 AnimatedSwitcher / AnimatedContainer / TweenAnimationBuilder。
- 普通窗口和最大化窗口使用不同断点，不再要求最大化才能正常排版。

## 目标构建环境

- Flutter 3.44.4 stable
- Dart 3.12.2
- Go 1.26.1 windows/amd64
- Windows 10/11 x64
