# V1.6 Bugfix

- 修复 sing-box INFO 因经 stderr 转发而被 UI 全部标成 `[ERR]`。
- 默认日志级别改为 warn；非 debug/trace 时抑制逐连接/逐数据包 INFO 刷屏。
- 修复 TUN 内部 172.19.0.0/30 探测流量经 direct 重新进入 TUN 的回环，解决空闲时“持续上传”假象/异常流量。
- 节点测速不再接受 0ms 作为有效结果；Clash API 返回 0 时回退 TCP 测量，最小显示 1ms。
- TUN 关闭且系统代理也关闭时，连接按钮自动启用 Windows 系统代理模式，无需管理员权限。
- UAC 管理员重启增加 `--resume-connect`，提升后自动继续连接；退出旧实例时不会被托盘拦截。
- 新增 Windows 系统托盘：单击/双击恢复，右键打开或退出；点窗口关闭按钮默认隐藏到托盘。
- 修复高 DPI 下初始窗口坐标被二次缩放导致启动位置偏到右下/中下方。

注意：当前环境没有 Flutter SDK，未在此处执行 Flutter Windows 编译；请使用用户已验证的 Flutter 3.44.4 / Dart 3.12.2 构建。
